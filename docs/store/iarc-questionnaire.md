Google Play: Play Console → **App content → Content rating → Start questionnaire**.

purchases, no ads, no gambling and no web access. The expected result is **Everyone /
PEGI 3 / 4+**.

## Target audience (Play, App content → Target audience and content)

This is a choice, not a fact.

- **Recommended: 13 and over.** The app suits everyone, but selecting any age under 13 puts
  the app under Play's Families policy, which adds requirements (teacher-approved program
  rules, specific disclosures) for no benefit to a focus timer.
- If you select ages under 13, the app still complies (it collects nothing and has no ads),
  but expect a longer review.
