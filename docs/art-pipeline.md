# Art pipeline

All the art in `assets/art/` is generated by `tool/generate_sprite_art.dart` in a
paper-cut style. (I also tried watercolour and flat finishes; they're still in the
generator for comparison.)

```sh
flutter test tool/generate_sprite_art.dart    # paints every plant and object
flutter test tool/render_art_preview.dart     # renders them as the app shows them
flutter test tool/generate_icons.dart         # app icon, every size
flutter test tool/generate_store_art.dart     # Play feature graphic
```

Output is deterministic: same seeds, same pixels. Each part keeps its seed across stages,
so the five stages look like the same plant growing. `tool/generate_art.dart` (the old
placeholder rasteriser) is retired and its test is skipped so it can't overwrite the art.

| File | Contents |
|---|---|
| `tool/sprite_art/wash.dart` | the painter: sheet, finishes, outline helpers, PNG encoder |
| `tool/sprite_art/parts.dart` | soil, stalk, leaf, clump, blossom, bud |
| `tool/sprite_art/flower.dart`, `plants.dart`, `forms.dart` | the fourteen plant forms at five stages, plus the icon seedling |
| `tool/sprite_art/decor.dart` | bench, birdbath, lantern, pond |

## Sprite format

Each sprite is two same-size PNGs plus a row in `assets/art/manifest.json`:

- `<name>.png`: the drawing, RGBA, transparent background
- `<name>.roles.png`: a role mask

70 plant rows (14 `PlantForm` × 5 `GrowthStage`) and 4 decor objects (`DecorKind`).

A `PlantType` (what a session length earns) comes in two or three forms, and a form is
one silhouette:

| Type | Forms |
|---|---|
| wildflower | `posy`, `spire` |
| herb | `leafy`, `sprig` |
| flower | `rayed`, `cup` |
| bush | `mound`, `spiked` |
| smallTree | `orchard`, `spreading` |
| largeTree | `broadleaf`, `weeping`, `conifer` |
| bonus | `tassel` |

Each `PlantSpecies` names its form. Species of one form share its drawings and differ
only in colour (`lib/src/garden/plant_palettes.dart`), so a new species needs no art
unless it needs a new shape. The seven bonus plants all use `tassel`.

Forms of a type are the same plant until the young stage, so their seed and sprout rows
point at one shared file named for the type (`herb_sprout.png`); the later stages are
named for the form (`sprig_young.png`). That makes 56 drawings behind the 70 rows, and
the app decodes each file once.

To add a form: add the `PlantForm` member, write its painter (hand the seed and sprout
to the type's existing painter), register it in `_painters` in
`tool/generate_sprite_art.dart`, and run the generator. It rewrites the plant rows from
scratch and deletes any file in `assets/art/plants/` the manifest no longer names.

Sprites are 512×512, with the plant standing on the bottom edge and centred
horizontally. The biggest anything is drawn is 264 px (timer screen at 3×). There's one
resolution, with no 2x/3x folders.

### Role mask

The colours shift at runtime with species, season and theme, so the mask says which
palette role each pixel belongs to:

| Channel | Plant | Decor |
|---|---|---|
| R | foliage | material (stone, wood, iron) |
| G | bloom | glow / water |
| B | soil | shadow |

0 keeps the drawing's own colour, 1 replaces it with the palette colour, and anything in
between mixes (overlay, not multiply). The mask's alpha is ignored.

A strong mask everywhere flattens the shading, so the drawing carries the light and dark
in warm neutrals, and the mask strength drops from 0.95 in highlights to 0.2 in the
darkest shadows.

A sprite without a mask is never tinted. That's fine for decor, but every plant needs one,
or it won't change colour with the seasons.

### Manifest

```json
{
  "plants": [
    {
      "form": "leafy",
      "stage": "sprout",
      "art": "assets/art/plants/herb_sprout.png",
      "roles": "assets/art/plants/herb_sprout.roles.png",
      "footprint": [0.31, 0.42, 0.69, 1.0]
    }
  ],
  "decor": [ ... ]
}
```

`footprint` is the bounding box of the non-transparent pixels as `[left, top, right,
bottom]` fractions. Hit-testing uses it: plants overlap the plots behind them, so the
full box would steal taps from the plant behind. It's stored rather than computed at
launch to keep alpha scans off the cold start. `form`, `stage` and `kind` must match the
enum names exactly, or the bundle fails to load.

## Loading

1. `ArtBundle.load` reads the manifest and decodes everything at launch.
2. `ArtGate` keeps the `OpeningFrame` up until that's done. Sprites paint synchronously
   and `GardenAtlas.bake` uses `toImageSync`, so the images have to be ready first.
3. `plantSpriteRegistryProvider` / `decorSpriteRegistryProvider` serve the image-backed
   registries. Everything above that (atlas, hit-test, export, sway) doesn't know or care.

No `manifest.json` means the app runs on the placeholder shapes. A manifest that's
present but broken (missing file, unknown enum name) throws, gets reported, and also
falls back to placeholders. The bundle is never half-applied.

## Tests

```sh
flutter test test/garden/art_bundle_test.dart test/garden/art_delivery_test.dart
```

`art_bundle_test` checks that every form and stage resolves, draws something, takes the
palette, and changes from one stage to the next.

`art_delivery_test` checks the files themselves:

- footprints match the alpha channel (within 1.5 px)
- plants sit on the bottom edge, centred
- alpha isn't thresholded (no jagged edges)
- art and mask are the same square, ≥ 264 px
- no opaque corners (no matte)
- every plant has a mask
- sprout → mature never shrinks (the seed is checked separately: it's a bean in the
  soil, so it's naturally wider than the first shoot)
- total size against the release-size headroom

Nothing checks that two plant forms look different. That one still needs eyes.

## Things to check on a device

The atlas bakes each sprite into a 192 px cell (`GardenAtlas.cellWidth`). At max zoom on a
3× phone that's drawn at ~660 px, so about 3.4× magnification. Paper-cut holds up fine
because it's flat colour, but raise `cellWidth` if it ever looks soft (it costs texture
memory).

## Drawn in code

Soil, sky and weather have no image files. They're colour applied to shapes, so seasons
and themes are just a palette table, and season changes can crossfade:

- plot tiles: `GardenAtlas._paintSoil` (material frame, soft shadow, soil sheet with a
  slightly irregular edge)
- sky: the skin colour with `PaperPainter` fibres on top
- weather: `WeatherPainter` (petals, leaves, paper snowflakes with small shadows)

## Icon and store art

`tool/generate_icons.dart` paints the seedling mark (`paintIconSeedling` in
`tool/sprite_art/plants.dart`) at 1024 px and writes:

- Android: `ic_launcher.png` at five densities, plus adaptive foreground/background
  layers (108dp, artwork inside the central 66dp) and `mipmap-anydpi-v26/ic_launcher.xml`
- iOS: all 15 sizes in the appiconset, opaque, with square corners

`tool/generate_store_art.dart` writes `docs/store/feature-graphic.png`. Store screenshots
come from `tool/screenshots/`.
